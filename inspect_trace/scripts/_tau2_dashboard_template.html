逐任务对比：原生 CLI vs 适配器（两个版本）

中间一栏是发现 Bug 3 之后、还没修复前的适配器（agent 侧被迫用 emulate_tools=true）；右边一栏是写了自定义 ModelAPI 去掉 strict 字段之后的适配器（agent 侧改回真正的原生 tool-calling，跟原生 CLI 用的机制一致）。逐条完全一致的数量没变（都是 6/10）——但"reward 真正不同"（唯一真正影响准不准的分歧）从 2 条降到了 1 条，另一条差异转移成了"reward 相同、终止方式不同"（对话轮数走向不一样，但最终判分没错）。机制对齐确实让两条路径更接近了，但没有完全消除差异（dual-control 模拟本身的随机性仍然存在，见下文"复现同一路径两次结果都不同"那条发现）。
